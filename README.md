# MainMicroservice1 🚀

Spring Boot микросервис, реализующий **циклический обмен сообщениями** по WebSocket между сервисами (MC1 → MC2 → MC3 → MC1), с сохранением результатов взаимодействия в базу данных и автоматическим завершением сессии по таймеру.

---

## ✨ Основная идея

MC1:

* запускает сессию взаимодействия
* отправляет первое сообщение по WebSocket
* принимает ответное сообщение от другого сервиса
* завершает цикл, сохраняет данные
* генерирует и отправляет следующее сообщение
* автоматически останавливается по таймеру

В конце логируется:

* ⏱ длительность взаимодействия
* 📊 количество отправленных сообщений

---

## 🧩 Архитектура

```
Controller  →  Service  →  WebSocket Client
                  ↓
              Repository (DB)
```


---

## 📡 REST API

### ▶️ Запуск взаимодействия

```
GET /message/start
```

**Что происходит:**

* открывается WebSocket-соединение
* создаётся новая сессия (`session_id`)
* отправляется первое сообщение
* запускается таймер авто-остановки

---

### ⏹ Остановка взаимодействия

```
GET /message/stop
```

**Результат:**

* цикл останавливается
* WebSocket сессия закрывается
* в лог выводится статистика

---

### 📥 Приём сообщения

```
POST /message/receive
```

**Тело запроса (JSON):**

```json
{
  "session_id": 1,
  "MC1_timestamp": "2026-01-01T10:00:00Z",
  "MC2_timestamp": "2026-01-01T10:00:01Z",
  "MC3_timestamp": "2026-01-01T10:00:02Z"
}
```

**Поведение:**

* сообщение финализируется (`end_timestamp`)
* данные сохраняются в БД
* генерируется и отправляется новое сообщение


---

## 🔄 Логика сервиса

* `start()` — старт новой сессии
* `cycle()` — основной цикл обработки
* `stop()` — завершение и логирование

## 🔌 WebSocket

### Подключение

WebSocket соединение создаётся при старте:

```java
connectWebSocket()
```

Используется `StandardWebSocketClient` + `TextWebSocketHandler`.

### Отправка сообщений

Сообщения отправляются **только после успешного подключения**:

* ожидание через `CompletableFuture`
* сериализация в JSON (`ObjectMapper`)
